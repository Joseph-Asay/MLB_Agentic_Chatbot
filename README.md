# MLB AI Data Assistant
An agentic chatbot using a Gemini API key which allows the program user to communicate through a LLM-type interface to get answers about MLB players and statistics.
## Files
- `MLB_Stats_Chatbot_clean.ipynb` — main Jupyter notebook
- `MLB_Stats_Chatbot.html` — rendered version of the notebook for easy viewing if GitHub notebook preview fails
### Description
The two csvs I used for this project were downloaded from Kaggle, cleaned, prepped and then combined into one master csv on which the chatbot would be trained. I elected to use a Gemini API key for this project primarily because I had seen it done before on an NBA chatbot. After creating the master dataset and setting up our call to the Gemini API came the most challenging part of this project which was training the AI model.
